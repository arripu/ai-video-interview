# Intake Question Ladder

Use this file to ask layered questions. Do not ask every question at once. Pick the smallest set that changes the plan.

## Round 0: Existing Context Check

Use when the user says "continue", "last time", "same project", "not finished", or references an existing folder.

- What project folder or prior output should this continue from, if it is not already clear?
- Which handoff index, manifest, prompt file, or latest recommended draft identifies the current state?
- What has already been approved, rejected, or paused?
- What is the next desired output: questions, plan, prompts, images, storyboard, video prompts, deck, PDF, or delivery package?

If files answer these, do not ask. Inspect first.

## Round 1: Project Base

Ask these first for a new project:

- What is the video's purpose: brand film, product seeding, IP worldbuilding, short story, launch material, investor/client pitch, social content, or another goal?
- Who is the audience: client, consumers, children, parents, fans, internal team, platform reviewers, investors, or buyers?
- Where will it be used: Douyin, Xiaohongshu, Bilibili, WeChat Channels, offline screen, exhibition, pitch deck, ad placement, website, or internal review?
- What length and format are needed: 15s, 30s, 60s, 90s, other; 16:9, 9:16, 1:1, or multiple versions?
- What does success mean: premium feel, clear selling point, cute character, brand recall, story clarity, client approval, fewer revisions, or conversion?

If the user is overwhelmed, ask only purpose, audience, platform, duration/aspect ratio, and success standard.

## Round 2: Materials And Current State

Ask after the project base is clear:

- What materials already exist: logo, product photos, character art, packaging, real photos, old video, reference video, PPT, script, brand book, music, subtitles?
- Which assets are final and must be locked?
- Which assets are only visual references or mood references?
- Which old drafts or directions are explicitly rejected?
- Is there a complete script, rough outline, one-line idea, or should the story be developed from scratch?
- Are voiceover, subtitles, BGM, sound effects, lyrics, Suno prompts, or editing notes needed?

For asset-heavy projects, ask the user to name or provide the most authoritative source for each important asset.

## Round 3: Content And Expression

Ask once materials are known:

- Is the video mainly telling a story, showing a product, building a character, explaining a function, or creating an emotion?
- Who or what is the main subject: person, pet, product, IP character, brand, user, place, or event?
- Which shots or moments must appear?
- Which images already exist in the user's mind and only need to be organized?
- What should be avoided: too ad-like, too childish, too realistic, too scary, too cheap, too crowded, too technical, too abstract?
- Which structure fits best: beginning-middle-end, problem-solution, reality-dream, before-after, day-in-the-life, adventure, emotional escalation, reveal, or montage?

## Round 4: Style And References

Ask before visual development:

- Which films, ads, animations, social videos, artists, brand films, or images should be referenced?
- What should be borrowed from each reference: color, lighting, shot language, texture, rhythm, editing, acting, worldbuilding, camera movement, or mood?
- What are the key style words: premium, dreamy, warm, toy-like, fairy-tale, real, tech, cute, healing, cinematic, documentary, fashion, playful?
- What is the style danger zone: AI noise, identity drift, cheap 3D, over-smoothing, horror pressure, pasted text, unfused materials, random props?
- Should the first output be a single calibration image, 4 style explorations, or a text-only direction board?

When a reference video is provided, never assume "copy everything". Ask which dimension matters.

## Round 5: Shots And Editing

Ask before keyframes or video prompts:

- Is the deliverable a single image, continuous keyframes, shot list, storyboard grid, 12-panel board, 24 keyframes, or 15-second video nodes?
- Must shots preserve one continuous space?
- What shot types are expected: push in, pull out, pan, tracking shot, overhead, low angle, close-up, flashback, match cut, object transition, split-screen, title card?
- What editing rhythm is desired: slow emotion, quick cuts, music beats, children's animation, ad film, trailer, light narrative, product demo?
- Are subtitle cards, logo moments, voiceover copy, screen text, captions, or end cards needed?
- Which shots must be approved before expanding, to avoid multiplying mistakes?

## Round 6: Delivery And Execution

Ask when the task becomes executable:

- Final deliverable: prompts, images, JSON, PDF, PPT, video prompts, client plan, internal execution doc, or delivery folder?
- Who will use it: internal executor, client reviewer, AI image tool, video tool, editor, designer, or platform uploader?
- Does every image need filename, shot number, role, source assets, prompt, and status?
- Is a manifest, contact sheet, approved/rejected index, or handoff file required?
- Should batch generation wait until a calibration image is approved?

If the user says "just do it", use reasonable defaults, but state the execution assumptions before large batch generation.
